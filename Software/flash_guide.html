BeeSMART

Software Flasher & Calibration Guide

Overview — Two Main Steps

  1. Flash software — Load new firmware onto your BeeSMART controller via USB.
  2. Calibrate scale — Connect everything and calibrate the scale so it weighs accurately.

Total time: ~5–10 minutes. No special tools needed.

1 Open the BeeSMART Software Flasher
Double-click BeeSMART_Flasher.exe (Windows) or run beesmart_flasher.py (Linux/Mac). The window below will appear.

BeeSMART Honey Dosing System v3.3.0
Tip: On Windows you may see a SmartScreen warning the first time — click More info → Run anyway.
2 Select the Firmware File
Click Browse and navigate to the firmware file you downloaded. It should be a .bin file (e.g. honeyDosing_v3_firmware.bin).

Tip: The status bar now shows "Ready to flash — connect your BeeSMART controller via USB". The tool is waiting for your device.
3 Connect the BeeSMART Controller via USB
Plug the BeeSMART controller into your computer with a USB cable. The flasher will automatically detect the device and start flashing.

Important: Do not unplug the USB cable while flashing is in progress. This could damage the controller.
4 Wait for Flashing to Complete
The progress bar will fill up and the status will turn green saying "Device flashed successfully" or "Done — ready for next device".

Tip: If you see "Flashing failed", try unplugging and re-plugging the USB, then repeat steps 3–4.
5 Close the Flasher
Once the status shows "Done", you can close the flasher window. Your BeeSMART controller now has the new software installed.

6 Connect the Scale to the Controller
Use the RJ45 cable to connect the BeeSMART scale to the BeeSMART controller. Plug one end into the scale and the other into the controller's RJ45 port.

On your phone, tablet, or computer, open the Wi-Fi settings and look for a network named BeeSMART-XXXXXXXX (the X's are unique to your device). Connect to it. No password is required.

Übersicht — Zwei Hauptschritte

  1. Software flashen — Neue Firmware über USB auf den BeeSMART-Controller laden.
  2. Waage kalibrieren — Alles verbinden und die Waage kalibrieren, damit sie genau wiegt.

Gesamtzeit: ~5–10 Minuten. Kein Spezialwerkzeug nötig.

Doppelklicken Sie BeeSMART_Flasher.exe (Windows) oder führen Sie beesmart_flasher.py (Linux/Mac) aus.

Overblik — To hovedtrin

  1. Flash software — Indlæs ny firmware på din BeeSMART-controller via USB.
  2. Kalibrér vægten — Forbind alt, og kalibrér vægten.

Tid: ~5–10 minutter. Intet specialværktøj nødvendigt.

1 Åbn BeeSMART Software Flasher
Dobbeltklik på BeeSMART_Flasher.exe (Windows) eller kør beesmart_flasher.py (Linux/Mac).
